## Concepts

### What is a Data Structure?

A **data structure** is a specialized format for organizing, managing, and storing data so that it can be accessed, updated, and manipulated efficiently in computer memory.

---

### Classification of Data Structures

Data structures are broadly categorized into two main types:

#### 1. Linear Data Structures
In a linear data structure, elements are arranged sequentially or linearly, where each element is attached to its previous and next adjacent elements.

* **Array**
* **Queue**
* **Stack**
* **Linked List**

#### 2. Non-Linear Data Structures
In a non-linear data structure, elements are not arranged sequentially. Elements can be connected to multiple other elements in a hierarchical or interconnected graph layout.

* **Tree**
* **Graph**
